# Node.js First Server 

My first **Node.js & Express.js server** project.

This project helped me learn the basics of building a backend server and creating APIs.

### 🛠️ Technologies

* Node.js
* Express.js
* JavaScript
* dotenv
* Nodemon
* Postman

### 📚 What I Learned

* Creating an Express server
* Creating GET & POST APIs
* Routes & Controllers
* Middleware
* Environment Variables
* Testing APIs with Postman

### ▶️ Run

```bash
npm install
npm run dev
```

Server runs on:

```text
http://localhost:8000
```
